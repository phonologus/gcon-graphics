# gcon-graphics

**Status: ARCHIVED.** Development has moved to [gcon/graphics](https://github.com/phonologus/gcon).

The display server for gcon (Go-based Icon). gcon runs Icon 9.5 programs
in Go and owns Icon's graphics semantics: the event queue, `Event()`,
the event keywords, window and context values. This server owns the
display. It opens windows, keeps the canvases, draws, and sends events
back over a protocol modelled on Plan 9's draw protocol. That keeps gcon
pure Go, with no cgo, and lets a display server be written in any
language.

**Status: just forked.** The drawing and platform code builds and links,
but the protocol is not designed yet, so the binary does nothing useful:
`bin/gcon-graphics -version` checks that SDL3 and Blend2D work.

## Origin

Forked from [icon-sdl](https://github.com/phonologus/icon-sdl), branch
`sdl-graphics` at 3b5a888: its SDL3 + Blend2D backend (`src/sdl/`, now
`src/`), the vendored, checksum-pinned dependencies (`deps/`), the X
colour-name tools (`sdl/tools/`, now `tools/`) and the Linux package
lists. The canvas layer's behaviour was checked there against Icon's X11
backend, pixel for pixel where possible. Its design notes are in
icon-sdl's `sdl/design.md`.

## Building

    ./build.sh

You need a C and C++ compiler and CMake. On macOS, the Xcode Command Line
Tools; on Linux, the packages in `linux-packages.txt` (Debian, Ubuntu) or
`linux-packages-fedora.txt` (Fedora). SDL3, Blend2D and AsmJit are built
statically from the tarballs in `deps/`, each checked against the SHA-256
in `deps/deps.lock`. Builds never use the network; only
`deps/update.sh` downloads, to change a pinned version.

## Layout

| Path | Contents |
|---|---|
| `src/canvas.c` | Canvases: Icon's drawing operations with Blend2D, combined as an X server would (all 16 drawops, patterns, clipping) |
| `src/plat.c` | Platform: SDL3 windows, presentation, events in X conventions, cursors |
| `src/fontmac.c`, `src/fontlinux.c` | Font lookup by CoreText or fontconfig |
| `src/xcolors.c` | X's colour names, generated by `tools/mkxcolors.py` |
| `src/sdlgfx.h` | The C interface to all of the above |
| `src/main.c` | The server (a stub for now) |
| `deps/` | Vendored sources and `deps.lock` |
| `docs/design.md` | Design notes |
